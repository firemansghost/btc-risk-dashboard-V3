## Repair on the same pull request

`status.json` `successor_provenance` is built by `buildSuccessorProvenance`. `successor_production_active` is true only when the nested candidate says `production_active: true`; the inactive candidates stay false. `writePublicationArtifacts` writes `latest.json` and `status.json` with that same function.

Cache reuse still checks the successor candidate, then rejects a missing or contradictory publication. A hit rebuilds the publication from the current candidate. It does not return the stored publication object. Legacy cache paths are still not written.

A later Term page that is malformed, a provider error, a network error, or an HTTP error is `MALFORMED_RESPONSE`, `PROVIDER_ERROR`, `NETWORK_ERROR`, or `HTTP_OTHER` / `HTTP_451`. Earlier rows from that provider are not scored. BitMEX `endTime` is an ISO date-time string. OKX `after` and Binance `endTime` stay millisecond cursors. JSON decode failures are caught.

`computeAllFactors` is what the dispatch test calls, with a fixed clock and supplied responses. Replacing `computeStablecoins` with an unavailable result fails `stablecoins_route_eligibility`.
