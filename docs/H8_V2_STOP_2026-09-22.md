## Why collection stopped

Scheduled Daily ETL attempt-1 failed from 2026-09-09 through 2026-09-21. The shared fatal symptom was `etf_flows: null (excluded) - farside_unavailable`. Farside itself continued to publish in ordinary browser access.

Transport probes using the frozen `computeEtfFlows()` request headers received HTTP 403, `server=cloudflare`, `cf-mitigated=challenge`, and title `Just a moment...` from:

- GitHub-hosted Ubuntu
- GitHub-hosted `macos-latest`
- GitHub-hosted `macos-15-intel`
- the local network used for the 2026-09-22 preflight

The same result occurred for the four frozen production Farside URLs and for `https://farside.co.uk/btc/` as a diagnostic control. Temporary diagnostic PR #54 was closed without merge.

H8 v2 protocol Section 26 requires the study to stop when compatibility cannot be proven, and requires a successor study before further scientific capture.
